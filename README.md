## 🧠 Overview

**BoxCutter** is a specialized Blender add-on for creating detailed hard-surface geometry through an interactive cutting workflow. It allows artists to draw shapes directly in the viewport and use them to build panels, openings, recesses, slices, and other structural elements.

Instead of setting up every boolean operation manually, users can work with responsive cutter controls while viewing the model in real time. This makes it easier to test different shapes, adjust proportions, and develop mechanical forms through rapid iterations.

The workflow can be applied to a variety of assets, including vehicles, machinery, props, product concepts, architectural objects, and futuristic designs. Custom cutters and adjustable operations provide additional flexibility when simple primitives are not enough.

**BoxCutter** also works alongside Blender's modifier-based modeling system, allowing artists to retain editable operations during the design process. This makes it a practical tool for building complex hard-surface assets while keeping the modeling workflow organized.

## 🚀 Key Features

| Feature | Description |
|----------|-------------|
| ✂️ **Viewport Cutting** | Draw and shape cutters directly in the 3D Viewport to create detailed geometric modifications. |
| 🔲 **Boolean Operations** | Produce cuts, slices, insets, intersections, and other boolean-driven forms through an interactive workflow. |
| 🖱️ **Interactive Editing** | Adjust cutter position, size, orientation, and shape while working directly on the model. |
| ⚡ **Rapid Prototyping** | Explore mechanical forms and design variations without repeatedly rebuilding boolean setups. |
| 🔄 **Non-Destructive Workflow** | Keep supported cutter and modifier operations editable while the asset continues to evolve. |
| 🧩 **Custom Cutter Shapes** | Combine prepared and customized cutter geometry for more specialized modeling tasks. |
| 📐 **Precision Controls** | Refine dimensions, offsets, angles, and placement for controlled hard-surface construction. |
| 🧱 **Panel & Recess Creation** | Build vents, slots, grooves, panels, cavities, holes, and layered surface details. |
| 🪞 **Symmetrical Modeling** | Use mirrored workflows to create consistent details across balanced hard-surface designs. |
| 🎨 **Bevel Workflows** | Combine cutting operations with bevel-based refinement for more defined surface transitions. |
| 🔧 **Modifier Compatibility** | Work with Blender's modifier system while developing and refining complex assets. |
| 🧠 **Blender Integration** | Perform cutting and hard-surface modeling tasks directly inside the Blender environment. |

## Additional Information for Windows Users

**BoxCutter** adds a direct viewport-based method for creating boolean-driven hard-surface details in Blender. Users can draw cutters over an existing model and modify their shape or placement without interrupting the design process.

The workflow is useful for mechanical objects, vehicles, props, product concepts, architectural elements, and other rigid assets. Different cutting modes and adjustable controls make it possible to develop both simple shapes and more elaborate surface details.

Its editable approach allows modeling decisions to be revisited as the project develops. Cutters and modifier operations can remain available for further adjustments before the final geometry is prepared.

**BoxCutter** keeps hard-surface construction inside Blender while making repetitive cutting operations faster and easier to manage.
